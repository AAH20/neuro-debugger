# neuro-debugger

> **Time-Travel Reverse Execution & Causality Forker for Frontier Agent Swarms**

Built for September 2026 frontier swarms (**Claude Opus 5.5**, **GPT-6 Astra**, **Gemini 3.8 Flash**, **DeepSeek V4.1-Flash**).

## Features
- **Deterministic Causality DAG**: Tracks backward ancestry (root-cause discovery) and forward impact (blast-radius analysis).
- **Reverse Execution & Rewind**: Step backward frame-by-frame through memory states, thought chains, and tool invocations.
- **Speculative Causality Forking**: Branch execution timelines at any past step, apply state overrides or prompt mutations, and simulate alternate outcomes.

## Installation
```bash
pip install -e .
```

## Quick Start
```bash
neuro-debugger --demo
```
